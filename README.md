# Bounce Breaker
Jogo Android nativo em Java. Arraste o dedo para trás e solte para impulsionar a bola. Quebre os blocos para avançar de fase. Toque no canto superior direito do cabeçalho para reiniciar.

## Gerar APK
Abra **Actions > Build Android APK > Run workflow**, aguarde a compilação e baixe o artefato `BounceBreaker-APK`. Dentro estará `app-debug.apk`.

Alternativa no Android Studio: abrir a pasta e escolher **Build > Build APK(s)**.
