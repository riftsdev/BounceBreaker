# 🎮 Bounce Breaker

Jogo Android 2D de bolinha: toque, puxe e solte para lançar a bola e quebrar obstáculos. Ganhe pontos e avance de fase!

## 📲 Baixar jogo para Android

### [⬇️ BAIXAR BOUNCE BREAKER APK](https://github.com/riftsdev/BounceBreaker/releases/download/latest/BounceBreaker.apk)

**Download público e gratuito.** Não precisa ter conta no GitHub.

> O botão funciona depois que a primeira compilação terminar com sucesso e publicar o APK na seção Releases. O APK atual é uma versão de testes, assinada com chave de depuração.

[Ver todas as versões](https://github.com/riftsdev/BounceBreaker/releases)

## Como jogar
Arraste o dedo para trás e solte para impulsionar a bolinha. Quebre todos os blocos para avançar de fase. Toque no canto superior direito para reiniciar.

## Desenvolvedores
O workflow em `.github/workflows/android.yml` compila o aplicativo e publica automaticamente `BounceBreaker.apk` na release pública `latest` após cada build bem-sucedido na branch principal. Também permite iniciar manualmente em **Actions > Build Android APK > Run workflow**.
